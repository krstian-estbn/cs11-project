## 🚀 Installation & Setup
### 1. Clone the repository
```
git clone https://github.com/krstian-estbn/cs11-project.git
cd cs11-project
```

### 2. (Optional) Install dependencies
If you want to play with the **bonus features**, install the extra dependencies:
```
pip install -r requirements.txt
```

## 🎮 How to Play
Run the game using 
```
python shroom_raider.py
```
